# 化工自定义板块设计

## 目标

在现有自定义板块体系中新增 `化工` 板块，复用当前配置、构建、历史数据和前端展示流程，不引入新的页面或特殊计算逻辑。

## 板块定义

- 板块代码：`huagong`
- 板块名称：`化工`
- 成分股数量：18
- 核心成分：万华化学、宝丰能源、华鲁恒升、卫星化学、巨化股份、云天化、兴发集团、荣盛石化、浙江龙盛、扬农化工、龙佰集团、藏格矿业
- 弹性成分：闰土股份、红宝丽、赤天化、和邦生物、百川股份、吉华集团

## 实现方式

在 `web/data/custom_boards_config.json` 的 `boards` 数组中追加板块。现有 `build_custom_board_data.py` 自动读取配置，因此无需修改构建器或前端。新增一个配置回归测试，验证板块存在、代码与名称正确、18只股票完整且没有重复。

随后使用现有构建脚本刷新最新自定义板块数据，再运行前端数据校验。历史日期不回填化工板块，避免大范围改写已有历史快照；化工板块从本次最新数据开始积累趋势。

## 验收标准

1. 配置中存在唯一的 `huagong` 板块。
2. 板块恰好包含确认的18只股票，代码与名称匹配且没有重复。
3. 最新 `custom_boards.json` 能生成化工板块数据。
4. `validate_web_data.py` 校验通过。
