# 创业板分钟数据 westock 拉取修复设计

## 目标

让 `build_cyb_trend_stats.py` 在 Windows 中可靠启动 WorkBuddy 同源的
`westock-data-clawhub`，成功拉取创业板指最近五个交易日分钟数据，并据此重算现有统计及
“0.8%下跌确认 + 0.8%反弹确认”独立面板。

## 范围

- 仅修改 westock 进程启动、输出校验和数据源优先级。
- 不修改原有15分钟连续阴线下探算法。
- 不修改主要下探的0.8%/0.8%确认算法。
- 不依赖 WorkBuddy 的私有安装目录或会话文件。

## 方案

1. Windows 下解析到 `npx.cmd`，以参数数组和 `shell=False` 启动，避免当前字符串命令被错误解析。
2. westock 作为主数据源；返回非零状态、错误文本或无法解析的数据时视为失败。
3. westock 失败后再调用东方财富，保留现有容错能力。
4. 使用单元测试验证启动参数和回退顺序；使用真实拉取验证最终分钟记录和最近五日输出。

## 成功标准

- 脚本不再寻找项目目录中的 `node_modules/npm/bin/npm-cli.js`。
- 成功获得创业板指分钟记录，或输出准确的 westock 业务错误而不是误判成功。
- 最近五个交易日重新生成，12、13、14日均包含 `majorDips` 等新字段。
- 全量单元测试、数据校验与页面布局测试通过。
