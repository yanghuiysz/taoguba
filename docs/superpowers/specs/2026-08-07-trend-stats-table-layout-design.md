# 趋势统计表格紧凑适配设计

## 目标

优化“趋势统计”新增板块中的汇总表和每日下探明细表，确保数字留在表格边框内，并尽量避免横向滚动条。

## 设计

- 两张表均采用固定表格布局，让浏览器严格在容器宽度内分配列宽。
- 缩小表头和单元格的水平留白，数字使用等宽数字特性并保持右对齐。
- 汇总表为日期、次数、深度、形态分别设置合理宽度；形态列允许在必要时换行。
- 形态列直接展示“特征 · 结论”的完整短句，不依赖鼠标悬停才能读懂；阈值细节继续保留在悬停提示中。
- 明细表压缩序号、类型、时间、深度、时长列，将“峰→谷”列留作弹性空间；峰谷数字允许在单元格内换行，不越过边框。
- 桌面和常见平板宽度不显示滚动条；仅在极窄屏下允许表格容器横向滚动作为安全兜底。

## 范围

- 修改 `web/custom.js` 中趋势统计表格的列标记。
- 修改 `web/custom.css` 中两张趋势统计表格的布局与响应式规则。
- 添加静态回归测试，检查关键布局约束持续存在。
- 不修改趋势统计的数据、计算口径、图表或其他板块。

## 验收标准

1. 常规桌面宽度下，两张表完整位于卡片内部且不出现横向滚动条。
2. 数字不得绘制到表格边框之外。
3. 表格列间距明显比当前更紧凑，仍保持可读性。
4. 极窄屏下内容优先换行；只有无法继续压缩时，才由表格容器提供横向滚动兜底。
5. 形态列完整展示“多而深 · 分歧加剧”等文字，不以省略号截断。

## 测试

- 自动检查表格使用固定布局、宽度约束、紧凑留白和安全换行规则。
- 运行现有测试，确认没有影响其他页面逻辑。
- 在实际页面宽度下进行视觉检查，确认表格无越界。
