# 板块资金净流入折线图设计

## 目标

精简自定义板块“趋势曲线”页签中的涨跌幅图，并新增一张按交易日展示的板块资金净流入折线图。

## 范围

- 仅删除涨跌幅图日期轴上方的“强”“弱”“强分歧”“弱分歧”等强弱标签。
- 保留标题说明中的板块量价、指数状态和背离判断。
- 保留现有板块涨跌幅图与正宗股成交额图。
- 在板块涨跌幅图下方、正宗股成交额图上方新增资金净流入图。

## 图表设计

- 标题：`资金净流入`。
- 副标题：`同花顺口径 · 正值流入 / 负值流出`。
- 使用板块 `trend` 中每日的 `mainNetInflow`，不派生新的资金指标。
- 纵轴以 0 为基准，金额以亿元为主要显示单位，并根据数据范围自动缩放。
- 使用一条连续的净额折线：正值区间为红色，负值区间为绿色；跨越零轴时在交点切换颜色。
- 每个有效节点显示格式化后的资金净额；正值带 `+`，负值带 `-`。
- 横轴日期与现有涨跌幅图一致，使用最近可展示的交易日序列。
- 当前选中日期沿用现有高亮带样式。
- 节点悬停信息包含完整日期、资金净额、数据来源和成分股覆盖率。

## 缺失数据

- `null`、`undefined` 或非数值资金值视为缺失，不转换为 0。
- 缺失日期不绘制节点；折线在缺失处断开，避免制造连续或零流入的假象。
- 全部日期均缺失时显示“暂无资金流数据”。

## 数据与兼容性

- 复用已接入的同花顺个股资金流每日快照及板块聚合结果。
- 不修改资金流抓取口径，也不把该数据称为交易所披露的机构资金。
- 不改变其他页签、排序、板块强弱计算或历史数据结构。

## 验收标准

1. 涨跌幅图日期轴不再显示任何强弱标签，日期正常显示。
2. 资金图位于涨跌幅图和成交额图之间。
3. 净流入为红色、净流出为绿色，跨零轴处颜色正确切换。
4. 缺失值不显示为 0，且折线在缺失日期断开。
5. 当前日期高亮、金额标签、来源和覆盖率信息正确。
6. 页面在现有桌面宽度和窄屏布局下均不溢出。

## 验证

- 为图表数据处理与缺失值行为添加 JavaScript 回归测试。
- 运行 `node --check web/custom.js`。
- 运行现有资金流测试与 `python scripts/validate_web_data.py`。
- 在本地页面分别检查正值、负值、跨零轴和缺失值场景。
