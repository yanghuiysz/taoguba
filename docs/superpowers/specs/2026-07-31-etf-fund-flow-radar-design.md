# ETF 资金雷达设计

## 目标

新增一个独立的“ETF资金雷达”，按收盘后每日更新 30 只规模和流动性较好的 A 股宽基、行业ETF，用ETF份额变化估算净申购资金，为市场风格、行业轮动和主线判断提供外部基准。

ETF数据不混入现有自定义股票板块的平均涨跌或资金流计算，避免成分股重复计权。

## 选取原则

1. 同一方向仅保留一只具有较好规模、成交活跃度和指数代表性的ETF。
2. ETF必须正常上市交易，不选联接基金、场外基金、增强策略或跨境ETF。
3. 宽基用于判断大盘风格，行业ETF用于判断资金轮动；不把宽基资金和行业资金直接相加。
4. ETF池固定维护，不因单日规模或涨幅变化频繁更换；出现清盘风险、长期流动性显著下降或指数代表性变化时才替换。

## 净流入计算口径

ETF成交额不等于ETF资金净流入。资金雷达使用份额变化估算一级市场净申购：

```text
当日份额变化 = 当日基金份额 - 上一交易日基金份额
当日估算净申购 = 当日份额变化 × 当日单位净值
```

仅在当日基金份额和当日单位净值均已发布、且日期一致时生成 `confirmed` 数据。任一项尚未发布时保持 `null` 并标记“待确认”，不使用收盘价生成临时估算，也禁止用成交额、主力净流入或错误日期替代。

同时计算：

- 1日估算净申购
- 5日累计估算净申购
- 20日累计估算净申购
- 当日涨跌幅
- 相对沪深300的1日、5日超额收益
- 当日成交额和相对5日平均成交额
- 最新基金规模（基金份额 × 单位净值）

## 状态标签

| 条件 | 标签 |
| --- | --- |
| 价格上涨且净申购为正 | 资金强化 |
| 价格下跌但净申购为正 | 逆势承接 |
| 价格上涨但净申购为负 | 上涨兑现 |
| 价格下跌且净申购为负 | 资金撤退 |
| 份额或净值日期不完整 | 待确认 |

持续性标签以最近5个交易日为窗口：累计净申购为正且至少3日净申购为正，标记“持续流入”；反向条件标记“持续流出”。

## 页面结构

新增独立ETF资金页面，并在总入口增加标签页。页面包含：

1. 数据日期、确认状态、30只ETF总览。
2. 今日净流入前10和净流出前10。
3. 5日持续流入方向。
4. 宽基资金偏好区，比较大盘、中盘、小盘、创业板和科创板。
5. 行业资金排名表，可按1日、5日、20日净申购、涨跌幅和成交额排序。
6. 每只ETF显示分类、代码、简称、净申购、份额变化、规模、成交额、相对收益和状态标签。

日更调度器在完整收盘后更新流程中调用ETF脚本。数据源失败时保留上一份有效数据，当前交易日显示失败原因和“待确认”，不写入虚假的零流入。

## 主线判断

ETF雷达只提供证据，不直接生成买卖建议。一个行业满足以下多数条件时可标记为“主线候选”：

- 1日和5日估算净申购均为正；
- 5日相对沪深300取得正超额；
- 至少3个交易日出现净申购；
- 当日成交额不低于5日均值；
- 对应自定义股票板块内部上涨广度和核心股表现同步。

## 验收标准

- 配置恰好包含5只宽基和25只行业ETF，代码无重复。
- 每只ETF的价格、份额、净值、规模和净申购均带数据日期与确认状态。
- 1日、5日、20日资金流计算使用份额变化，不使用成交额冒充。
- 缺失数据保持 `null` 并显示“待确认”。
- 页面能正确展示宽基偏好、行业排名及资金状态标签。
- ETF数据校验、现有数据校验和项目测试全部通过。
