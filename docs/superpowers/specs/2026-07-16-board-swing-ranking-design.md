# 板块级波段排行设计

## 目标

在现有复盘仪表盘中新增独立的“板块排行”Tab，按与“板块内韧性排行”相近的3日、5日统计维度横向比较全部自定义板块，并支持从排行直接进入对应板块的“波段观察”详情。

## 页面与交互

- 在现有详情 Tab 中，将“板块排行”放在“波段观察”旁边。
- 该页面不依赖当前左侧选中的板块，始终展示全部可用板块。
- 表格采用完整横向布局，列为：
  - 排名
  - 板块
  - 综合排序
  - 3日成交额
  - 5日成交额
  - 3日资金净流入
  - 5日资金净流入
  - 3日涨幅
  - 5日涨幅
  - 3日相对大盘
  - 5日相对大盘
  - 最大回撤
  - 状态
- 默认按综合排序降序；所有数值列均可点击表头进行升序或降序排列。
- 点击板块名称后，选中该板块并切换到它的“波段观察”详情。
- 正值使用现有红色上涨样式，负值使用现有绿色下跌样式。
- 缺失或覆盖不足的数据展示“暂无”，不得替换为0。

## 数据口径

页面直接复用已经加载的最近15个交易日板块趋势，不新增网络请求或独立数据文件。

- 3日、5日成交额：对应窗口内板块每日总成交额之和。
- 3日、5日资金净流入：对应窗口内有效的板块主力净流入之和；每个日点继续遵守现有80%成员覆盖门槛。
- 3日、5日涨幅：使用板块每日正宗股平均涨幅按交易日复利计算。
- 3日、5日相对大盘：板块窗口复合涨幅减去同窗口上证指数复合涨幅。
- 最大回撤：使用最近5个有效交易日的板块复合净值序列计算最大回撤。
- 所有统计截止到页面当前所选日期；不得使用该日期之后的数据。

成交额和资金流采用板块成员股合计值，不做单股平均或板块规模归一化。

## 综合排序与状态

综合排序保持与当前板块内排行一致的决策倾向：

- 58%：5日成交额得分。
- 42%：5日涨幅得分。
- 两项均按全部板块当期横截面做0至100的最小—最大归一化。
- 若所有板块某项数值相同，该项统一记50分。
- 任一核心项缺失时综合排序显示“暂无”，并排在有效板块之后。

状态由综合分与风险共同决定，并严格按以下顺序匹配：

- 最大回撤超过8%或5日相对大盘为负：`震荡/转弱`。
- 综合分不低于78且5日相对大盘为正：`趋势增强`。
- 综合分不低于65：`可观察`。
- 其余：`偏弱`。

风险条件优先于分数条件，避免高成交额但明显跑输大盘的板块被标记为增强。

## 代码边界

- `web/custom-swing.js`：板块窗口统计、横截面归一化、综合分、排序、Tab注入、表格渲染和点击跳转。
- `web/custom-swing.css`：新增表格宽度、状态标签和响应式样式，沿用现有颜色变量。
- 新增Node行为测试：执行生产统计函数，覆盖窗口截止、总额聚合、资金缺失、复合涨幅、相对大盘、回撤、排序与跳转标记。

不修改 Python 数据结构，不新增后端接口，不改动现有“板块内韧性排行”。

## 错误与边界处理

- 可用交易日少于3日时，3日与5日窗口指标均显示“暂无”。
- 可用交易日达到3日但不足5日时，仅3日指标有效，综合排序显示“暂无”。
- 资金流窗口内只要有任一日为缺失，整个对应窗口资金值显示“暂无”，防止部分和被误认为完整总额。
- 大盘窗口缺失时，相对大盘显示“暂无”，但不影响成交额、资金流和板块涨幅展示。
- 点击板块跳转时若目标板块不存在，保持当前页面，不抛出异常。

## 验收标准

- 页面出现独立“板块排行”Tab，并展示全部23个现有板块。
- 表格各项指标与现有15日原始趋势逐日计算结果一致。
- 默认按综合分降序，数值表头排序可切换方向。
- 点击板块名称能进入对应板块“波段观察”。
- 缺失资金流不显示0，未来日期不进入计算窗口。
- 新增测试、现有波段测试和数据验证全部通过。
